# CyberTyper 3D ⚡

An action-packed 3D Sci-Fi Typing Defense Game built with **Three.js** and **Web Audio API**.

## 🎮 Play Online
- Live on GitHub Pages: `https://arshmehra82642-ai.github.io/cyber-typer-3d`

## 🚀 Features
- **True 3D Graphics:** Hyperspace warp starfield, cyber neon grid floor/ceiling, 3D fighter ship turret, gyroscopic enemy drones.
- **Procedural Audio:** Web Audio API procedural sound engine with laser blasts, sub-bass explosions, keystroke clicks, and combo fanfare chimes.
- **Smart Target Locking:** Type the first letter of an enemy drone to lock laser targeting.
- **Tactical Controls:** Press `BACKSPACE` or `ESC` to unlock target and switch priority.
- **Difficulty Tiers:** Cadet (Easy), Hacker (Medium), Overlord (Expert).
- **Telemetry:** Real-time WPM, Accuracy %, Combo Multipliers, and Shield Integrity.
- **Mobile Friendly:** Fully responsive with on-screen virtual keyboard support.

## 🛠️ Built With
- Pure Vanilla JavaScript (ES6+)
- Three.js (WebGL 3D Engine)
- Web Audio API (Procedural Sound FX)
- HTML5 Canvas & Cyberpunk CSS3
